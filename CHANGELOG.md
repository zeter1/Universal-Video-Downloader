# История изменений

### 2026-10-11 — Windows-сборка 6.3 из актуального main

- Версия приложения обновлена с 6.2 на 6.3 для Windows-выпуска с уведомлениями о завершении задач и блокировкой пути сохранения во время загрузки.
- Подготовлены актуальные русские заметки выпуска для GitHub Releases.
- Упаковка выполняется существующим GitHub Actions workflow: компиляция, offline regression tests, Windows PyInstaller, проверка встроенных инструментов через `--self-test` и SHA-256.

### 2026-10-11 — Уведомления о завершении и блокировка пути

- Добавлено постоянное уведомление поверх окон после скачивания, конвертации и обработки аудио; отдельные состояния успеха, ошибки и отмены.
- Добавлено открытие текущей папки сохранения из уведомления и обновление пути при его изменении.
- Во время задачи поле пути сохранения и кнопка «Обзор» заблокированы. Завершение из worker передаётся через очередь, которую обрабатывает главный поток Tk.
- Источник изменений: загруженный пользователем архив `Skachat_video_online.zip`; сохранены совместимость PyInstaller, CI и документация GitHub.
- Исправлено: восстановление элементов пути сохранения и показ уведомления безопасны при частично инициализированном GUI.
