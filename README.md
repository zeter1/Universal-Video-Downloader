# Universal Video Downloader

**Universal Video Downloader** — Windows-приложение на Python/Tkinter для загрузки видео с сайтов, поддерживаемых `yt-dlp`. Программа ориентирована на удобный итоговый файл: для видео используется MP4 с качеством до **1080p**, а аудио при необходимости можно сохранить в MP3.

Проект старается избегать лишнего перекодирования: сначала выбирает подходящие MP4/M4A-потоки, затем при необходимости делает быстрый lossless remux, и только в крайнем случае использует перекодирование в H.264/AAC.

## Что демонстрирует проект

- интеграцию `yt-dlp`, FFmpeg и ffprobe в единый пользовательский workflow;
- выбор стратегии обработки медиа с приоритетом качества и минимизации лишнего transcoding;
- проверку итогового файла после скачивания и объединения потоков;
- fallback-цепочку от совместимых исходных потоков к remux и только затем к перекодированию;
- модульную структуру большого desktop-приложения;
- диагностические данные для проблем, зависящих от внешних сайтов и медиатулов;
- специальную карту кода и инструменты определения минимальной области изменений для AI-assisted разработки.

## Возможности

- загрузка видео через `yt-dlp`;
- качество до 1080p;
- итоговый контейнер MP4;
- скачивание и конвертация аудио в MP3;
- FFmpeg / ffprobe для обработки и проверки результата;
- приоритет remux без потери качества;
- fallback на H.264/AAC, если совместимый MP4 нельзя получить проще;
- модульная архитектура;
- диагностические логи;
- инструменты для быстрой навигации Codex по проекту.

## Установка

1. Установите актуальный Python для Windows.
2. Установите FFmpeg и ffprobe и добавьте их в системный `PATH`.
3. Скачайте проект через **Code → Download ZIP** или Git:

```bash
git clone https://github.com/zeter1/Universal-Video-Downloader.git
cd Universal-Video-Downloader
```

4. Установите Python-зависимости:

```powershell
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python video_downloader.py
```

## Как пользоваться

1. Запустите программу.
2. Скопируйте ссылку на видео с поддерживаемого сайта.
3. Вставьте ссылку в поле программы.
4. Выберите нужный режим: видео или MP3.
5. Для видео выберите доступное качество, максимум — 1080p.
6. Укажите папку сохранения.
7. Запустите загрузку.
8. После скачивания программа при необходимости объединит потоки через FFmpeg и проверит итоговый медиафайл.

Если исходные потоки уже совместимы с MP4, программа старается не перекодировать их. Это ускоряет обработку и не создаёт дополнительную потерю качества.

## Как формируется итоговый MP4

```text
Подходящие MP4/M4A потоки
        ↓
Загрузка через yt-dlp
        ↓
Lossless remux в MP4 при необходимости
        ↓
H.264/AAC transcoding только как fallback
        ↓
Проверка результата через ffprobe
```

## Проверка проекта

CI выполняет компиляцию Python-кода и полный набор offline regression tests. Локально тот же базовый уровень можно проверить так:

```powershell
python -m compileall -q video_downloader.py problem_log_validator.py src scripts tests
python -m unittest discover -s tests -v
```

Эти проверки не заменяют реальное скачивание с конкретного сайта: доступность сайтов и форматов зависит от внешних сервисов и текущей версии `yt-dlp`.

## Важное замечание

Поддержка конкретных сайтов зависит от `yt-dlp` и может меняться, когда сайты обновляют свои API, защиту или форматы выдачи. При проблемах рекомендуется сначала обновить `yt-dlp` и посмотреть диагностические логи программы.
