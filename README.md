# Universal Video Downloader

**Universal Video Downloader** — универсальное Windows-приложение на Python/Tkinter для скачивания видео с интернет-ресурсов, поддерживаемых `yt-dlp`, с качеством до **1080p** и возможностью конвертации в **MP3**.

Программа ориентирована на получение удобного и совместимого итогового файла: для видео целевым форматом является **`.mp4`**. Сначала приложение предпочитает MP4/M4A на нужном качестве, затем при необходимости выполняет быстрый **lossless remux** в MP4 без повторного кодирования. Перекодирование в **H.264/AAC** используется только как крайний fallback.

## Возможности

- скачивание видео в качестве до **1080p**;
- формирование итогового видео в контейнере **MP4**;
- конвертация видео и аудио в **MP3**;
- использование `yt-dlp` для загрузки медиаконтента;
- обработка и проверка медиа через **FFmpeg** и **ffprobe**;
- приоритет быстрой обработки без лишнего перекодирования;
- модульная структура проекта для удобного сопровождения и развития;
- документация и служебные инструменты для эффективной работы с **Codex**.

## Требования

- Python;
- `yt-dlp`;
- FFmpeg;
- ffprobe.

Python-зависимости проекта перечислены в [`requirements.txt`](requirements.txt).

## Запуск

```bash
python video_downloader.py
```

## Как формируется итоговый MP4

1. Программа старается скачать совместимые потоки **MP4/M4A** в доступном качестве до 1080p.
2. Если контейнер требует преобразования, выполняется быстрый **lossless remux** в MP4.
3. Перекодирование в **H.264/AAC** применяется только тогда, когда получить совместимый MP4 более лёгким способом невозможно.
