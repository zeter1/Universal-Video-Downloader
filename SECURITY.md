# Security and privacy

Universal Video Downloader взаимодействует с внешними сайтами, `yt-dlp`, FFmpeg, локальными файлами и сетевыми настройками. В отдельных сценариях пользователь может работать с cookie, приватными ссылками, прокси или другими чувствительными данными.

## Сообщение об уязвимости

Если вы обнаружили проблему, которая может раскрывать авторизационные данные, небезопасно обрабатывать URL/пути, выполнять неожиданные команды или затрагивать локальные файлы, не публикуйте чувствительные детали в открытом issue до предварительного контакта.

Связь: **zeter11@gmail.com**

## Никогда не публикуйте в issue

- cookie;
- токены;
- приватные ссылки с временными параметрами доступа;
- логины/пароли;
- конфигурацию прокси с учётными данными;
- другие секреты авторизации.

Если проблема воспроизводится только с приватным URL, сначала опишите поведение без публикации самой ссылки.

## Диагностические журналы

Логи yt-dlp и FFmpeg могут содержать URL, параметры запроса, локальные пути и технические сведения о файлах. Перед публикацией удалите чувствительные значения.

## Зависимости

Поддержка сайтов во многом зависит от актуальности `yt-dlp`. При диагностике ошибок загрузки рекомендуется воспроизводить проблему на текущей версии зависимости, но обновление сторонней библиотеки не заменяет проверку безопасности входных данных и локальных операций проекта.

## Локальные файлы

Программа должна сохранять результат только в ожидаемую пользователем директорию. При сообщении о проблемах с путями не публикуйте полную структуру личных каталогов, если это не требуется для воспроизведения.
