# Изменения Windows-сборки

- Добавлена готовая автономная Windows-сборка `Universal-Video-Downloader.exe`.
- В бинарник включены проверенные runtime-инструменты: `yt-dlp 2026.08.19`, Deno `2.9.7`, FFmpeg и ffprobe.
- Исправлено определение каталогов в frozen/PyInstaller-режиме: настройки и диагностические данные остаются рядом с пользовательским EXE, а встроенные инструменты берутся из runtime-каталога bundle.
- Добавлен packaged self-test: перед публикацией сборка реально запускает встроенные `yt-dlp`, `deno`, `ffmpeg` и `ffprobe`.
- Для `yt-dlp.exe` и архива Deno в CI проверяются закреплённые SHA-256 перед упаковкой.
- Бинарник и отдельный файл SHA-256 публикуются только после успешных regression tests и packaged smoke-test.

- Исправлена Windows-совместимость regression test для frozen-путей: ожидаемые пути теперь сравниваются после нормализации через `Path.resolve()`.

## Проверка

Эта сборка подтверждает запуск встроенного runtime/toolchain в GitHub-hosted Windows runner. Реальное скачивание с конкретных сайтов остаётся внешним runtime-сценарием и зависит от доступности сайта, сети и текущего поведения источника.
