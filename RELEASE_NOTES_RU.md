# Изменения Windows-сборки

- Обновлена программа до самой новой версии из переданного проекта.
- Для YouTube добавлен приоритет русской аудиодорожки (`ru`) с безопасным fallback на любую доступную дорожку, если русской нет.
- Сохранён существующий приоритет готового 1080p-потока: новая языковая логика не откатывает исправление выбора качественного объединённого потока.
- Исправлена работа `Ctrl+C` и `Ctrl+V` в поле ссылок при русской раскладке клавиатуры; обработчик учитывает и Tk keysym, и физические Windows keycode.
- Расширены regression tests для выбора русской аудиодорожки, fallback-логики, 1080p-приоритета и горячих клавиш буфера обмена.
- Сохранена действующая автономная Windows-упаковка: EXE включает `yt-dlp`, Deno, FFmpeg и ffprobe и проходит packaged self-test перед публикацией.

## Проверка

Локально выполнены `compileall` и unit/regression tests: **85 тестов**, из них **80 успешно**, **5 пропущены** как интеграционные сценарии, требующие внешнего `yt-dlp`/runtime-окружения или поставляемых примеров логов. Дополнительно GitHub Actions повторно выполняет тесты на чистом runner, собирает Windows EXE и запускает self-test встроенного toolchain перед созданием Release.

Реальное скачивание с конкретных сайтов остаётся внешним runtime-сценарием и зависит от доступности сайта, сети и текущего поведения источника/`yt-dlp`.
