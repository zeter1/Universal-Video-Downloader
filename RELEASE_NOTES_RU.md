# Universal Video Downloader — Windows-сборка 6.3

**Дата выпуска:** 11 октября 2026 года  
**Источник:** актуальная ветка `main` репозитория `zeter1/Universal-Video-Downloader`. Функциональные изменения включены в коммиты `fd9469f` и `b0e0d3e`.

## Что нового

- После завершения скачивания и конвертации показывается отдельное уведомление поверх окон; предусмотрены состояния успешного выполнения, ошибок и отмены.
- В уведомлении отображаются длительность задачи и папка сохранения; кнопка **«Открыть папку»** открывает актуальную директорию.
- Во время активной задачи поле пути сохранения и кнопка выбора папки блокируются, чтобы исключить случайную смену каталога посреди обработки.
- Результат фоновой загрузки передаётся в интерфейс через очередь и обрабатывается в основном потоке Tkinter.
- Исправлено восстановление элементов управления и отображение уведомлений при частично инициализированном интерфейсе.

## Существующие возможности

- Скачивание видео через `yt-dlp` с приоритетом MP4 до 1080p и предпочтением русской аудиодорожки YouTube, если она доступна.
- Извлечение и обработка аудио в MP3.
- Обработка и проверка видео через FFmpeg и ffprobe; приоритет совместимых потоков и remux перед перекодированием.

## Windows EXE и проверка

GitHub Actions выполняет компиляцию и offline regression tests на Linux, затем повторяет тесты на Windows и создаёт автономный `Universal-Video-Downloader.exe` с помощью PyInstaller. В EXE включаются `yt-dlp`, Deno, FFmpeg и ffprobe. Перед публикацией выполняется `--self-test` встроенных инструментов и формируется файл `Universal-Video-Downloader.sha256.txt`.

Сборка публикуется как **Prerelease**. EXE не имеет коммерческой цифровой подписи; Windows SmartScreen может предупредить о новом приложении. Работоспособность конкретных видеосайтов зависит от их изменений, сети и текущего поведения `yt-dlp`. Не загружайте контент в нарушение прав и правил сервисов.
