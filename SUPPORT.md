# Поддержка и сообщения об ошибках

Если загрузка или конвертация завершилась ошибкой, сначала проверьте проблему на актуальной версии проекта и обновлённом `yt-dlp`.

Для bug report особенно полезны:

- версия/ревизия программы и версия Windows;
- сайт-источник;
- режим: видео или MP3;
- выбранное качество;
- версия `yt-dlp`;
- точные шаги воспроизведения;
- релевантное сообщение `yt-dlp`, FFmpeg или ffprobe;
- безопасный фрагмент диагностической сессии из `Логи проблем/`.

## Что проверить перед issue

1. Повторяется ли проблема после обновления `yt-dlp`.
2. Доступны ли `ffmpeg` и `ffprobe` из `PATH`.
3. Работает ли ссылка в браузере без дополнительной авторизации.
4. Не является ли сбой временным изменением сайта-источника.

## Приватность

Не публикуйте cookie, токены, приватные ссылки, авторизационные заголовки и другие секреты. Если диагностический файл содержит URL с чувствительными параметрами — отредактируйте их перед публикацией.

Для обычных ошибок используйте GitHub Issue Form в этом репозитории. Потенциальные уязвимости сообщайте по правилам из [`SECURITY.md`](SECURITY.md).
