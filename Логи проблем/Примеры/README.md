# Постоянные примеры диагностики

Сценарии:

- `success` — чистое успешное выполнение;
- `recovered` — ошибка, повтор и восстановление;
- `failed` — окончательная нерешённая ошибка;
- `crashed` — фатальное необработанное исключение;
- `legacy_schema3` — запись старой схемы 3, нормализуемая валидатором в схему 4.

В каждом сценарии `events.jsonl` и `ai_problem_log.jsonl` должны быть
побайтно одинаковыми. Проверка:

```powershell
python problem_log_validator.py --examples
```

Ожидаемые результаты находятся в `expected_results.json`.
